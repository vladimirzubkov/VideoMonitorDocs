VideoMonitor

Welcome to the VideoMonitor page.

In short, VideoMonitor is a graphical shell for FFmpeg that we tried to make convenient, stable, and still flexible for everyday work. Instead of keeping and retyping long command lines, you get an interface that stores the settings, sits in the tray, and does a lot of the routine for you.

A few of the extra pieces:

  • yt-dlp integration for downloads from the network (we call these miners).
  • Step-by-step FFmpeg processing so effects can be chained (denoise, then stabilize).
  • A schedule so heavy encodes can wait for night or the weekend.
  • CPU limits, including a cap on how many cores encoding may use, so a background encode does not take the machine away from other work.
  • Separate output directories – the job can be repeated safely, and the originals stay untouched.
  • Notifications by Telegram or email when a job finishes or fails.

Note: The program is in a public beta for now.

Where to start​

  1. Runners – the FFmpeg shell, and the presets that ship with it.
  2. Miners – the yt-dlp shell, and how a miner can hand files to a runner.
  3. Usage scenarios – real ways to use VideoMonitor.

The options live on the Settings tab. They are stored in VideoMonitor.toml next to the program. You can edit that file yourself; it is loaded at startup, and a later edit in the interface writes the file again.

If you found a bug or have an idea, please post it on GitHub (VideoMonitorDocs).

For playback, we recommend MPC-HC (Media Player Classic). It handles subtitles and chapters (like on YouTube), you can shape it to the way you watch, and it feels right (on the GitHub page see Releases).
