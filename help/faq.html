FAQ

Where is configuration stored?​

Beside the executable: VideoMonitor.toml (main) and optional VideoMonitor.local.toml (notification secrets). The UI saves on change. See Getting started.

Runners vs Miners — which do I use?​

Runners transcode with FFmpeg from folders or a manual file list. Miners download with yt-dlp from URLs, folders, or playlist files. They can be linked so a finished download starts an encode.

Why does encode not start immediately?​

Common causes:

  • Runner Paused or outside work schedule (Scheduled on tab).
  • Sequential mode while another runner holds the queue (Queued(N)).
  • Start when lower waiting for CPU to drop (Settings → CPU).
  • Empty path, bad mask, or manual queue empty.
  • Path vitality Suspect / Down on network paths.

Why does yt-dlp fail or show wrong titles?​

  • Run Verify yt-dlp setup in Settings; install Deno if prompted.
  • On Windows, non-ASCII titles need UTF-8 pipe handling (built in; update yt-dlp if ancient).
  • Check User-Agent and rate limits in Settings → Miners (yt-dlp).

How do presets work?​

Plain click loads a slot. Ctrl+click writes the current options into that slot after confirm. Ctrl+Shift+click on Runners builds a preset chain. Typing edits the row; with auto-save on, the active slot updates after a short pause. See Presets.

Playlist export blocks the UI?​

It should not — exports run on a background thread with a FIFO queue. Hold Ctrl+Space on Runners to show Playlist buttons; queue multiple runners one after another.

How do I see all keyboard shortcuts?​

F1 in the app, About tab cheat sheet, or Shortcuts.

How do I hide the Performance tab?​

Ctrl+W on Performance, or uncheck Show Performance tab. Ctrl+Shift+T brings it back without leaving your current tab.

Where are Telegram/mail passwords stored?​

Prefer VideoMonitor.local.toml or enter in Settings UI (encrypted fields in main file migrate to local on save).

How do I report a bug or suggest a feature?​

About → Bugs and ideas, or the Bugs and ideas page. Reports go to public GitHub Issues on VideoMonitorDocs (not email).

Program updates?​

Set GitHub owner/repo in config; About → Update program or startup policy under Settings → App behavior → Updates.
