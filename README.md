# VideoMonitor Help

Public user guide and issue tracker for **VideoMonitor** (download with yt-dlp, encode with FFmpeg, presets, schedules, tray, notifications).

**Documentation:** [https://vladimirzubkov.github.io/VideoMonitorDocs/](https://vladimirzubkov.github.io/VideoMonitorDocs/)

This repository is only the latest published snapshot. Each update replaces it with one new commit, so earlier history is not kept here. The working source stays in the private repository.

**Download:** [https://vladimirzubkov.github.io/VideoMonitorDocs/download](https://vladimirzubkov.github.io/VideoMonitorDocs/download)

In the app, **About → Online help** opens the same site. **About → Bugs and ideas** opens a new issue.

## Bugs and ideas

[Open an issue](https://github.com/vladimirzubkov/VideoMonitorDocs/issues/new)

A bug and an idea use this same page. Say which one it is in the title. Do not paste passwords, tokens, or a settings file that contains them.
