Performance Tab

The Performance tab shows live system and per-runner/miner metrics while work is active (and optionally in the background on other tabs).

Charts​

Typical series:

  • CPU — system usage vs CPU limit line from Settings.
  • Memory — system and process RSS (Windows sampling prefers largest child under ffmpeg/yt-dlp when helpers wrap the real process).
  • Per-runner stacks — encode speed, session time, ETC, estimated size (legend columns configurable).

Monochrome theme uses fixed gray stack colors; idle layers may hide fill to avoid baseline smear.

Legend and “pocket”​

When Allow hidden runners/miners work is off, legend lists only visible strip rows. When on, all configured slots appear; hidden/active-off rows may show (pocket) suffix.

Letters in legend match configured runner_letter / miner_symbol for chart correlation.

Settings that affect this tab​

SettingEffect
Show Performance tabPin/unpin tab; Ctrl+W hides when active; Ctrl+Shift+T restores without switching.
Monitor stats live on backgroundKeep sampling on Runners/Miners/Settings (lower rate). Turn off if UI stutters.
CPU limit / Adaptive loadCap and dynamic nudge of encoding CPU (CPU and Resources).
Limit logical coresFFmpeg thread cap; Cores used may show * if running job started under old cap.

Sticky system summary​

Optional floating System card when enabled in Settings — stacks over scrollable chart area.
