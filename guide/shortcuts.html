Keyboard Shortcuts

Press F1 in the app for the full overlay. Esc closes it. This page mirrors the product reference (English).

F2 toggles the single-key layer (status bar: Shortcuts ON/OFF). When ON, letter keys control runners/miners instead of typing in FFmpeg/yt-dlp fields — turn OFF to edit options freely.

F2 layer (Runners / Miners)​

KeyAction
F2Toggle shortcuts layer
NToggle Notify for selected row
GStart / Go (runner; respects blocks)
DDrill (miner)
RRemove runner/miner (confirm when needed)
BToggle status bar rotation
S / PSequential / Parallel launch
MMonitor unprocessed files
CProcess on FFmpeg change
3 / #Make playlists (e.g. M3U8)
ORunners: path highlight; Miners: open-path highlight — pairs with Enter/double-click behavior
TWork schedule modal
WRemaining-work-only display (runners)
1–8Jump to visible row by slot
0Hide last visible row
9Show one more row (up to 8 visible)
j / kSelection down / up
h / lPrevious / next preset slot
AAbout tab
QExit without confirmation
Y / NYes / No in dialogs (with focus)

With F2 ON, Shift+A/R/D/Q stay bulk actions (below). Typing S/P/M/C/… on Runners changes global options, not miner row fields.

General​

ShortcutAction
Ctrl+Tab / Ctrl+Page DownNext main tab
Ctrl+Shift+Tab / Ctrl+Page UpPrevious main tab
Ctrl+WHide Performance tab (when Performance active)
Ctrl+Shift+TRestore hidden Performance tab without switching to it
Ctrl+Alt+Left/RightReorder Runners/Miners/Performance strip slots (when both RM visible)
Ctrl+ITheme ring forward (System → Light → Dark + HC)
Ctrl+Shift+ITheme ring backward
Ctrl+BTable “lips” off → Bow → Full → off
Ctrl+Shift+BLips cycle reverse
Ctrl+[Denser UI (toward Ultra compact)
Ctrl+]Wider UI (toward Wide)
Tab / Shift+TabNext / previous runner or miner
↑ / ↓Same as Tab on Runners/Miners
Ctrl+↑/↓ or Ctrl+J/KMove selected runner/miner row in strip
Ctrl+DDuplicate row (double N on output path)
Ctrl+H / Ctrl+LSwap active preset with neighbor
EnterPreset chain editor if slot active; else path/open vs scan per tab and O mode
Ctrl+EnterBrowse source (runner path / miner src)
Ctrl+Shift+EnterRunners: add/select files dialog
Ctrl+Alt+EnterBrowse output destination
Ctrl+SpaceRunners: hold to show Playlist buttons; Miners: focus download queue
Ctrl+Shift+SpaceRunners: focus manual file queue
F1This help overlay

Bulk (Shift+)​

ShortcutAction
Shift+AAdd runner or miner
Shift+RRemove selected (confirm)
Shift+SStart all runners (when F2 off; else S is Sequential)
Shift+DStart all miners (drill)
Shift+QStop all runners and miners

Pause / stop​

Depends on Monitor unprocessed files:

Monitor ONMonitor OFF
Ctrl+Shift+P pause all runnersCtrl+P pause all runners
Ctrl+Shift+S stop all runnersCtrl+S stop all runners
Ctrl+Shift+M pause all minersCtrl+Shift+P pause all miners
Ctrl+Shift+D stop all minersCtrl+Shift+D stop all miners

Editing​

ShortcutAction
Ctrl+Z / Ctrl+YUndo / redo (context-dependent)
Ctrl+ASelect all in FFmpeg / yt-dlp editors
:qExit without confirmation

Selected files table (Runners)​

When the manual queue is focused:

ShortcutAction
Ctrl+↑/↓Move selection or contiguous block (see Runners)
Shift+RRemove selection without confirm dialog
Delete / BackspaceRemove with confirm if enabled
↑/↓, Tab, table lipsMove cursor in sorted display order
Ctrl+click lipMove row(s) one step (like Ctrl+↑/↓)

F2 suppresses runner quick keys 1–8, j/k, 0/9 while editing Mask, Output subdir, Path, or FFmpeg fields.

Settings tab​

ShortcutAction
Ctrl+ZRemove last word from Settings search filter
Ctrl+Shift+Z / Ctrl+YRedo search token
Arrow keys on numeric fieldsStep values (see in-app tooltips)
