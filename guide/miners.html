Miners

A miner is one yt-dlp job: a source (URL, directory, playlist file, or web shortcut) and a destination folder. Drill is the main action — it builds a download queue, then downloads items.

Row layout​

BlockPurpose
ControlDrill / Pause / Stop; Queued(N) in sequential miner queue.
Src path / URLSource root or link.
yt-dlp optionsArgument string + preset bank (same model as runner FFmpeg).
DestinationOutput directory (required before download).
Download queueTable of discovered items (URL, title, formats, status).

Drill phases​

list → verify (--print title/duration) → scan (-J formats/subs) → download
  • Listing — BFS for directories; skips common junk folders (.git, node_modules, …).
  • Verify — lightweight per-URL check.
  • Scan — format/subtitle discovery for queue UI.
  • Download — yt-dlp execution; progress in row and Performance.

Pause scan after current stops listing after the active pass.

Download queue UI​

  • Video / Audio summary chips by resolution; bold chips appear in all rows — click to paste format token into yt-dlp field.
  • Subtitles — expand section to pick languages; merged into one --sub-langs argument.
  • Sortable columns; cursor moves in visual sort order (arrows, lips, Tab).
  • Monitor column — periodic re-check vs history when global monitoring is on.

Opening paths and titles​

Settings → App behavior (and O with F2):

  • Enter / double-click on miner name: open destination, or Browse if source empty.
  • URL title probe: UTF-8 safe; first title may copy sanitized folder name to clipboard for destination naming.

Drag-and-drop​

When enabled (Settings → App behavior), drop onto a miner row:

  • Folder, .m3u/.m3u8, url-mask .txt
  • One web shortcut (.url, .webloc, .desktop) at a time

Mixed folder + URL in one drop is rejected.

Stream pair warning​

If yt-dlp options select video-only or audio-only format, a modal offers to add the paired stream or drill without merging.

Sequential queue​

Same family as runners: only one miner drills at a time when sequential; others show Queued on the button and plain Queued in status column.

Linking to runners​

Pick linked runner letter in row or Settings. Optional auto-start of linked runner after miner batch completes (Coordination).

Deno and yt-dlp setup​

Settings → Miners (yt-dlp) — verify install, install Deno via detected package manager or official script, Restart program so PATH updates.
