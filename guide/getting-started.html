Getting Started

What you need​

  • Windows, Linux, or macOS build of VideoMonitor.
  • FFmpeg and ffprobe on PATH (required for Runners).
  • yt-dlp on PATH (required for Miners).
  • Writable output directories; network paths (UNC) are supported with optional path vitality probing.

First launch​

  1. Place VideoMonitor.toml beside the executable (or let the app create defaults when you add a runner/miner).
  2. Start the program. Open Settings → Miners (yt-dlp) and run Verify yt-dlp setup if downloads are planned.
  3. Open Runners, select row A, set Path to originals, Mask, FFmpeg options, and Output (sub)dir, then press Start (or G with F2 shortcuts on).
  4. For a quick test, point at a small folder with one or two short MP4 files and a conservative CRF preset.

The status column moves through states such as MONITORING, RUNNING, IDLE, Queued, Paused. The Performance tab shows CPU and per-runner speed when monitoring is enabled.

Minimal config example​

[app]
log_level = "info"

[[runners]]
name = "Archive"
path = "D:\\Videos\\Incoming"
mask = "*.mp4"
ffmpeg_args = "-c:v libx264 -crf 23 -c:a aac -b:a 192k"
output_subdir = "encoded"
overwrite_original = false

[[miners]]
name = "Channel"
source_path_or_url = "https://www.youtube.com/@example"
destination_dir = "D:\\Downloads\\Channel"
ytdlp_args = ""

Adjust paths for your machine. UI edits write back to the same structure.

Runners vs Miners (one minute)​

RunnerMiner
ToolFFmpegyt-dlp
SourceFolder + mask, or Selected files listURL, folder, .m3u, .url shortcut, url-mask file
OutputFiles under runner destination / subdirFiles under miner Destination
Start controlStart / GoDrill (builds queue, then downloads)

They can be linked so a miner completion optionally starts a paired runner (Settings → Coordination).

Secrets and notifications​

Put Telegram bot token and mail app password in VideoMonitor.local.toml or enter them in Settings → Notifications. The main TOML can stay free of secrets for backup or version control.
