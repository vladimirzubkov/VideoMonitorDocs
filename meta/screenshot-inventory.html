Screenshot inventory

PNG files go under Documentation/static/img/ using the paths below. Until a file exists, pages show a placeholder via <Screenshot src="…" />.

Capture recipe​

  • Theme Light, density Normal, unless the caption says otherwise.
  • Client area about 1920×1080 (or 1920×1130). Crop chrome if needed.
  • Hide tokens, cookies paths that identify you, and mail passwords. Dummy paths are fine.
  • PNG, no heavy compression artifacts.
  • Raw captures live in the workspace Screenshots/ folder (names may include (untrimmed)). Publish with:
python tools/crop_docs_screenshots.py

That script trims white margins on (untrimmed) shots, pixelates Chat ID / mail / cookies fields, copies into Documentation/static/img/, and slices preset banks from the full Runners/Miners windows.
