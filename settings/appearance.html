Appearance

Top-left Settings group under Coordination. Theme, density, accent, tray icon chrome, interface language, and how linked rows look.

OptionTypical defaultMeaning
ThemeLightLight / Dark / System. High contrast is a separate checkbox (dark-based).
Interface densityNormalUltra-compact → Wide. Changes control size and padding.
Adjust content size accordingly—Scale text/controls with density
Program wide—Apply that size adjustment to the whole window
Icon styleColorMonochrome vs color for program / tray icons
Accent colorblueClick the swatch for named colors and roles (primary, hover, text on accent)
Interface languageEnglishUI strings (en / ru, …)
Bold active runner/miner—Emphasize the selected row
Show brackets on linked runner/miner—Visual link between miner letter and runner
Show numbers when linked to multiple—Count when one miner maps to several runners
Show with the same style on the Performance tab—Reuse linked-row chrome on Performance
Apply search in Settings—Filter Settings rows from the search box
Include tooltips in search—Match tooltip text too
Show time in program title—Clock in the window title
Show program start time—Session start time in the title

Tablet / Wide density enlarges touch targets (About Donate, Settings buttons). See About.
